Notes
-----
- Each subfolder is self-contained.
- The figures are generated by the Python script in the corresponding code/ folder.
- The PDFs are compiled from the corresponding main.tex.
- File 3 uses self-normalized importance sampling to evaluate posterior means and Hessians.

Regeneration
------------
From each subfolder:
  python3 code/generate_figures.py
  pdflatex main.tex
  pdflatex main.tex
