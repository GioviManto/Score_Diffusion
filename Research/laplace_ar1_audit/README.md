# Laplace AR(1) audit package

This package contains a corrected short presentation note, a full derivation compendium, the code used to regenerate the figures, and a numerical check report.

## Folder structure

- `presentation/short_presentation_note.tex`
- `presentation/short_presentation_note.pdf`
- `companion/derivation_compendium.tex`
- `companion/derivation_compendium.pdf`
- `figures/`
  - `fig01_innovations_and_kernel.pdf`
  - `fig02_score_slices.pdf`
  - `fig03_hessian_diagonal.pdf`
  - `fig04_hessian_heatmaps.pdf`
- `code/`
  - `ar1_diffusion_utils.py`  : corrected Gaussian and Laplace formulas
  - `make_figures.py`         : regenerates all figures in `figures/`
  - `run_checks.py`           : independent numerical verification script
  - `check_report.txt`        : output of the verification script

## Main mathematical changes

1. The short presentation is now Laplace-first. The Gaussian case appears only as the benchmark in which the score Hessian is constant.
2. The finite-chain Gaussian AR(1) precision matrix has been corrected at the boundary entries.
3. The deterministic control is kept, but its interpretation is corrected: its dense noised precision comes from a rank-one propagation mechanism, not from the same Markov fill-in mechanism as the stochastic AR(1) chain.
4. The normal-Laplace convolution formula in the original code has been corrected.
5. The exact `K=1` Laplace benchmark is derived fully:
   - exact characteristic function after OU noising,
   - exact one-dimensional density reduction,
   - exact score formulas,
   - exact effective-precision formulas.
6. The old `K=2` elementary closed-form claim is not kept. The companion states only the exact nested integral representation that is currently justified.

## Numerical checks

The file `code/check_report.txt` is generated by `code/run_checks.py` and verifies:

- Gaussian finite-chain precision against direct inversion,
- the small-time Neumann expansion,
- the deterministic-control inverse formula,
- the corrected normal-Laplace convolution formula,
- the exact `K=1` density reduction against an independent double integral,
- the exact `K=1` score and Hessian formulas against finite differences.

## Rebuild instructions

From the project root:

```bash
cd code
python3 run_checks.py
python3 make_figures.py

cd ../presentation
pdflatex -interaction=nonstopmode -halt-on-error short_presentation_note.tex
pdflatex -interaction=nonstopmode -halt-on-error short_presentation_note.tex

cd ../companion
pdflatex -interaction=nonstopmode -halt-on-error derivation_compendium.tex
pdflatex -interaction=nonstopmode -halt-on-error derivation_compendium.tex
```

The short note is the presentation-facing document. The companion is the line-by-line derivation document for defending every formula.
