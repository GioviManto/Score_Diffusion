Toy Model 6 — Score on the Circle

Order Parameter SDE, Separable Exact Score, and Analytical Propagator Error

Part of the series: Score-Based Diffusion for Dynamic Objects  ·  2026

Post-Achilli direction. This is the first toy model with non-Gaussian geometry: a stochastic process on the circle with separable radial and angular dynamics. The score factorises exactly in polar coordinates. The key result is that the score field is fully determined by a 4-dimensional order parameter φ(u) satisfying a closed ODE — the "SDE for the order parameter" requested after the Achilli meeting. The rotation propagator P = Rω has an analytical relative error ε(u, t) that we derive and plot.

§1 Two-Temperature Dynamics on the Circle

A particle moves in ℝ² with polar coordinates (r, θ). The two degrees of freedom are governed by independent SDEs with separate temperatures:

Radial (OU, confinement at r = 1): dr(u) = (1 − r(u)) du + √(2 T_r) dB_r(u) Angular (BM with drift): dθ(u) = ω du + √(2 T_θ) dB_θ(u)

The independence of r and θ means the joint distribution factorises in polar coordinates at every internal time u:

p₀(r, θ | u) = p_r(r | u) · p_θ(θ | u)

Marginals (closed form)

Radial OU marginal: m_r(u) = 1 + (r₀ − 1) e^{−u} [mean, decays to 1] σ²_r(u) = T_r (1 − e^{−2u}) [variance, grows to T_r] p_r(r|u) ≈ N(m_r(u), σ²_r(u)) [Gaussian approximation, exact for T_r→0] Angular BM with drift: θ_mean(u) = θ₀ + ω u [mean angle, rotates at rate ω] σ²_θ(u) = 2 T_θ u [angular variance, grows as diffusion] p_θ(θ|u) = Wrapped-N(θ_mean(u), σ²_θ(u)) [wrapped Gaussian on S¹]
Two limiting cases: (a) T_θ → 0: pure rotation, no angular spreading; the propagator P = R_ω is exact. (b) T_r → 0: particle stays on the unit circle; dynamics reduce to Toy Model 3 but with angular diffusion.

§2 Exact Score via Polar Decomposition

The log-density in Cartesian coordinates (x, y) = (rcosθ, rsinθ):

log p₀(x,y|u) = log p_r(r|u) + log p_θ(θ|u) − log r + const

The −log r term arises from the Jacobian of the polar → Cartesian map (the volume element is r dr dθ = dx dy, so p(x,y) = p(r,θ)/r). Differentiating:

s_r(r, u) = ∂_r log p_r = −(r − m_r(u)) / σ²_r(u) [radial score] s^{1D}_θ(θ, u) = ∂_θ log p_θ = −(θ_adj − θ_mean(u)) / σ²_θ(u) [angular score] Full 2D Cartesian score, decomposed in ê_r = (cos θ, sin θ) and ê_θ = (−sin θ, cos θ): s(x, u) = ( s_r(r,u) − 1/r ) ê_r + ( s^{1D}_θ(θ,u) / r ) ê_θ

The −1/r correction to the radial component arises from the Jacobian term. It pushes the score inward near the origin (anti-confining) and is negligible for r ≈ 1.

Structure of the score. Unlike Toy Models 1–5 (where s was linear in x), here s(x, u) is nonlinear in x (through the 1/r and θ = atan2(y,x) dependence). Nevertheless it remains analytically exact and fully tractable. The two components — radial and tangential — are geometrically separated and independently parametrised by (m_r, σ_r) and (θ_mean, σ_θ) respectively.

§3 Score as Order Parameter: the 4-ODE System

The score field s(x, u) is entirely determined by the order parameter vector

φ(u) = ( m_r(u), σ²_r(u), θ_mean(u), σ²_θ(u) ) ∈ ℝ⁴

via the formula in §2. The order parameters satisfy a closed, linear ODE system:

dm_r / du = −(m_r − 1) [OU: decay toward r=1, rate 1] dσ²_r / du = 2(T_r − σ²_r) [variance: relaxes to stationary value T_r] dθ_mean / du = ω [angular mean: pure drift, no restoring force] dσ²_θ / du = 2 T_θ [angular variance: grows linearly (diffusion)]

These are all exactly solvable: m_r(u) = 1 + (r₀−1)e^{−u}, σ²_r(u) = T_r(1−e^{−2u}), θ_mean(u) = θ₀+ωu, σ²_θ(u) = 2T_θu.

Precision form: Riccati equation

For the angular direction, introduce the precision κ_θ(u) = 1/σ²_θ(u) = −J_s^{tang} (the Jacobian eigenvalue in the tangential direction). From dσ²_θ/du = 2T_θ:

dκ_θ / du = −2 T_θ · κ²_θ [Riccati equation for angular precision] Solution: κ_θ(u) = 1 / (2 T_θ u) [algebraic decay; starts at ∞, falls as 1/u]

For the AR(1) model in continuous time (x evolves as dx = −γx du + σ_η dW), the radial precision satisfies the analogous Riccati:

dκ_r / du = 2γ κ_r − σ²_η κ²_r [Riccati: two-fixed-point structure] Fixed points: κ_r = 0 (unstable) and κ_r = 2γ/σ²_η = 1/σ²_∞ (stable)
Unification. The Riccati equation dκ/du = 2γκ − σ²_η κ² governs the precision (= minus the Jacobian eigenvalue) for all Gaussian dynamics: the circle (γ=0, angular), the AR(1) (γ>0, 1D), and the rotating AR(1) in 2D (matrix Riccati). This is the core "SDE for the order parameter" from the Achilli direction.

§4 Rotation Propagator: Exact Formula and Analytical Error

The rotation propagator

Define P = R_ω (rotation by angle ω) acting on score fields as:

[P · s_u](x) = R_ω · s_u( R_{−ω} · x ) i.e. evaluate s_u at the back-rotated point, then rotate the output.

When is P exact? Substituting the score formula from §2 and using r invariance under rotation:

[P · s_u](x) radial component: s_r(r, u) − 1/r [unchanged, since r is rotation-invariant] [P · s_u](x) tangential: −(θ − θ_mean(u) − ω) / σ²_θ(u) · (1/r) Compare s_{u+1}(x) tangential: −(θ − θ_mean(u+1)) / σ²_θ(u+1) · (1/r) = −(θ − θ_mean(u) − ω) / σ²_θ(u+1) · (1/r) [since θ_mean(u+1)=θ_mean(u)+ω]

The two are identical iff σ²_θ(u+1) = σ²_θ(u), i.e. T_θ = 0. The relative error for T_θ > 0 is:

ε_tang(u) = | σ²_θ(u+1) / σ²_θ(u) − 1 | = 2 T_θ / (2 T_θ u) = 1/u [t=0, clean score]

After OU diffusion (diffusion time t)

Forward noise adds (1−e^{−2t}) to the effective angular variance per unit r² (Cartesian OU → polar):

σ²_θ,eff(u, t) ≈ σ²_θ(u) + (1 − e^{−2t}) [OU noise adds to angular spread] ε(u, t) = ( σ²_θ,eff(u+1,t) − σ²_θ,eff(u,t) ) / σ²_θ,eff(u, t) = 2 T_θ / ( 2 T_θ u + (1 − e^{−2t}) )
Large u, small t → ε ≈ 1/u (small)
Many steps → angular variance accumulated, ratio → 1. Propagator nearly exact.
Small u, small t → ε = 1/u (large)
Few steps → variance ratio is large. Propagator fails: score field at u+1 is narrower.
Intermediate t → ε < 1/u
OU noise dominates angular width → variance ratio → 1 faster. Phase II sweet spot.
Large t → ε → 0 (trivially)
s(x,u,t) ≈ −x for all u; propagator ≈ identity everywhere.

§5 After OU Diffusion: the (u, t) Plane

Each frame is independently corrupted by OU noise at diffusion time t:

X_t(u) = a(u) e^{−t} + √(1 − e^{−2t}) · Z, Z ~ N(0, I₂)

The noised score at (x, u, t) is computed via the Tweedie formula (Monte Carlo, exact up to sampling error):

s(x, u, t) = E_{a ~ p₀(·|u)} [ (a e^{−t} − x) / (1−e^{−2t}) | X_t = x ] ≈ Σ_k w_k(x) · (a_k e^{−t} − x) / (1−e^{−2t}) where w_k(x) ∝ N( x; a_k e^{−t}, (1−e^{−2t}) I ) [Gaussian mixture weights]
